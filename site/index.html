📺 On a TV with the Downloader app

The easiest way on Android TV, Google TV, Fire TV and TV boxes: no computer, no USB stick.

  1. Install Downloader (by AFTVnews) from the TV's app store (Google Play or the Amazon Appstore).
  2. Let it install apps: Google TV / Android TV: Settings → Apps → Security & restrictions → Unknown sources → Downloader → On. Fire TV: Settings → My Fire TV → Developer options → Install unknown apps → Downloader → On (no Developer options? Settings → My Fire TV → About → press the device name 7 times).
  3. Open Downloader and type this code in the box, then press Go:
    4564305
    or the address sherazi5110.github.io/stream-goat/tv
  4. When it has downloaded, press Install, then Open. Downloader offers to delete the file afterwards: press Delete, it isn't needed any more.

It always gets the newest version. If the TV says "App not installed", uninstall the old Stream Goat first (back up first: Settings → Updates and backup), or type the code 2193283 instead (the universal version: works on every device, bigger download; or the address sherazi5110.github.io/stream-goat/apk).

🛡️ Google Play Protect warning or block

On some phones and TVs, Google Play Protect warns that Stream Goat "can install harmful apps", blocks the install or its updates, or later disables or removes the app by itself (it "disappears" from the TV).

Why: Stream Goat isn't on the Play Store, it installs its own updates (so it needs Android's "install unknown apps" permission), and it downloads extensions, like CloudStream. Play Protect flags apps that work this way. Stream Goat is free and open source: anyone can read its code on GitHub.

  1. At the warning: press More details, then Install anyway.
  2. Still blocked, or the app keeps disappearing? Turn off Play Protect's scanning: Phone or tablet: Play Store → your profile picture → Play Protect → ⚙ (top right) → turn off Scan apps with Play Protect. Google TV / Android TV: Play Store → your profile → Settings → Google Play Protect → turn off scanning. Then install Stream Goat again.
  3. App gone from the TV? Settings → Apps → See all apps: if Stream Goat is there but disabled, press Enable; if it isn't there, install it again.

Turning Play Protect off is your choice: it also stops it checking other apps. If you turn it back on, it may disable or remove Stream Goat again. Only download Stream Goat from this website or its GitHub page.
